# Спецификация комплектующих (BOM) — CYBER-DECK ONE (V5.0 Dual-ESP32)

Актуальный список деталей под тонкий плоский корпус **`248 x 228 x 32 мм`** на **2 голых платах `ESP32-S3`** + **`PCF8575`** (без клеммных шилдов и без транзисторов), с экраном `~2.9"` SPI, стерео-выходом `3.5 мм` и встроенным моно-динамиком в плоской камере `~180 мл`.



## 1. Вычислительный кластер, Дисплей и Прошивка

| Компонент | Кол-во в сборке | Статус / Запас | Примечание |
| :--- | :---: | :---: | :--- |
| **ESP32-S3 DevKitC-1 N16R8** (голые платы, 16 МБ Flash / 8 МБ Octal PSRAM) | **2 шт.** | Из заказа (3 в запас) | Устанавливаются без шилдов на печатный мостик `pcb_bridge` |
| **16-bit I2C IO Expander `PCF8575`** (модуль-платка) | **1 шт.** | Уже есть (из V1-V2) | Опрос 8 кнопок (`BRAIN` + `SOUND`) и 4 тумблеров для `ESP #1` |
| **Дисплей `~2.9"` (SPI, окно `~70 x 34 мм`)** | **1 шт.** | К закупке / выбору | OLED (`SSD1309` / `SSD1322 256x64`) или TFT/IPS `2.8-2.9"` SPI (`5` пинов + `3.3V/GND`) |
| **Мини USB-хаб `SL2.1A` (4 порта, под пайку)** | **1 шт.** | Из заказа | Занято 2 порта из 4 (подпаивается к `GPIO 19/20` обеих плат) |
| **Врезной разъем `USB-C 6-Pin`** | **1 шт.** | Из заказа | Общий вход питания `5 В` и данных `D+/D-` на заднем торце |



## 2. Органы управления панели

| Компонент | Кол-во в сборке | Статус / Запас | Примечание |
| :--- | :---: | :---: | :--- |
| **Энкодеры `EC11` (голые, вал 20 мм, с гайкой)** | **12 шт.** | Из заказа (8 в запас) | 4x3 матрицы (только фазы `A/B`; опц. клик на `BPM`) |
| **Потенциометры `10 кОм` (`WH148 B10K`, с гайкой)** | **3 шт.** | Из заказа | Вертикальный EQ-стрип (`HIGH / MID / LOW`) на `ESP #2` |
| **Кнопки металлические `12 мм Momentary LED 3-6V`** | **12 шт.** | Из заказа (12 в запас) | Ровно `3 x (2x2)`: 4 зеленых, 4 синих, 4 красных; LED прямо на шину `5 В` |
| **Тумблеры `MTS-103` (3-pin SPDT, ON-OFF-ON)** | **3 шт.** | Из заказа (2 в запас) | Строки 1-3: `GENRE`, `ENG`, `SPACE` |
| **Тумблеры `MTS-102` (3-pin SPDT, ON-ON)** | **4 шт.** | Из заказа (1 в запас) | Строки 1-3 (`MOOD`, `DKILL`, `FXOFF`) + верхний `PWR` |
| **Тумблер `MTS-203` (6-pin DPDT, ON-OFF-ON)** | **1 шт.** | **Докупить** | Для **True Stereo** овердрайва `DRV` (резьба `M6`, как у `MTS-103`) |
| **Колпачки-ручки на вал 6 мм** | **15-16 шт.** | Проверить наличие | 12 на энкодеры + 3 на EQ (+ 1 крупный на `PAM8406`) |



## 3. Стерео-аудио тракт, Встроенный динамик и Питание

| Компонент | Кол-во в сборке | Статус / Запас | Примечание |
| :--- | :---: | :---: | :--- |
| **ЦАП `GY-PCM5102` (`PCM5102A` Stereo I2S DAC)** | **1 шт.** | Из заказа (1 в запас) | Подключен к `ESP #2` (`SCK` обязательно замкнуть на `GND`) |
| **Подавитель земляной петли `BA3121`** | **1 шт.** | Из заказа | Оба канала (`L+R`) после `PCM5102A` |
| **Диоды `1N4148`** | **10 шт.** | Из заказа (из 100) | По 5 диодов на канал (`L` и `R`): 2 на Soft Clip + 3 на Hard Asym |
| **Резисторы `1.5 кОм` (или `1-2.2 кОм`, `0.25 Вт`)** | **2 шт.** | **Докупить** | **Обязательно!** По 1 шт. в каналы `L` и `R` между `BA3121` и диодами `1N4148` |
| **Резисторы `1 кОм` (`0.25 Вт`)** | **2 шт.** | **Докупить** | Пассивный моно-сумматор `L+R -> PAM8406 L_IN` после размыкателя `PJ-392A` |
| **Гнездо `PJ-392A` (3.5 мм, 5 контактов с размыканием)** | **1 шт.** | Из заказа (4 в запас) | Выход **True Stereo** (наушники / AUX / внешний BT TX) с автоотключением динамика |
| **Усилитель `PAM8406` (5 В, с крутилкой громкости)** | **1 шт.** | Из заказа | Используется **только канал L**; крутилка = `VOLUME` на панели |
| **Широкополосный динамик `diymore 2"` (5 Вт, 4 Ом)** | **1 шт.** | Из заказа (1 в запас) | В плоской герметичной камере `~180 мл` под подиумом `+7.5 мм` |
| **Конденсаторы электролитические `1000 мкФ 10 В`** | **2 шт.** | Из заказа | 1 шт. на общую шину `5 В`, 1 шт. прямо на питании `PAM8406` |



## 4. Механика корпуса, Пайка и Опции

| Позиция | Номинал / Размер | Кол-во | Зачем нужно |
| :--- | :--- | :---: | :--- |
| **Латунные вплавляемые втулки `M3`** | `M3 x 4 x 4.2 мм` (или `M3 x 5 x 4.5`) | **17 шт.** | 9 (дно `bottom_lid`) + 4 (мостик `pcb_bridge`) + 4 (подиум динамика `speaker_pod`) |
| **Винты `M3` впотай + цилиндрические** | `M3 x 8 мм` / `M3 x 10 мм` | **17 шт.** | Сборка дна, мостика и притягивание динамика к подиуму |
| **Винты `M2.5 x 6 мм`** | `M2.5` (саморезы или винты) | **4 шт.** | Скрытое крепление платы экрана `~2.9"` с изнанки `top_shell` |
| **Силиконовые ножки самоклеящиеся** | `D=12 мм`, высота `2-3 мм` | **4 шт.** | В посадочные выемки дна — создают приток воздуха под корпус |
| **Синтепон (или вата)** | 1 небольшая щепотка | — | Рыхло уложить в камеру динамика — увеличивает виртуальный объем на `+15-20%` |
| **Монтажный провод `26-28 AWG`** | Многожильный силиконовый, 4-6 цветов | 1 набор | Короткие шлейфы (`4-8 см`) прямой пайки к `ESP32-S3` |
| *(Опционально)* **Внешний Bluetooth TX-передатчик** | Адаптер `3.5 мм AUX -> Bluetooth TX` (с режимом `TX`!) | 1 шт. | Втыкается в `PJ-392A` для беспроводной игры в автомагнитолу или Bluetooth-колонку |



## 5. Исключенные компоненты (в запас / для других проектов)

* **Третья (и 4-5) платы `ESP32-S3`**, **клеммные базы `S3 Expansion Board A` (5 шт.)**, **малые `0.96" OLED` (5 шт.)**, **транзисторы ШИМ-подсветки**, **модуль `MicroSD`**, **пьезодатчики `SAMIORE ROBOT`**, **лазеры `VL53L0X`**, **матрица `WS2812B`**, **второй динамик `diymore 2"`**, **плата `NE5532`** — полностью исключены из финальной ревизии.



## 6. Бюджет питания (`5 В`)

| Режим работы | 2x `ESP32-S3` + Экран `2.9"` + `PCF8575` + `PCM5102A` + `BA3121` | 12x LED кнопок (прямо на `5 В`) | `PAM8406` (1 канал L) | Итоговый ток |
| :--- | :---: | :---: | :---: | :---: |
| **От ПК (`USB Safe Mode`)** | ~285 мА | ~90 мА | ~60 мА (лимит 20%) | **~435 мА** *(безопасно для USB 2.0)* |
| **Наушники / AUX / BT TX** | ~285 мА | ~90 мА | 0 мА (динамик выкл.) | **~375 мА** *(работает от USB в авто)* |
| **Встроенный динамик (`100%`)** | ~285 мА | ~90 мА | ~400-850 мА (пик) | **~0.8 - 1.2 А** *(Powerbank / БП `5 В / 2 А`)* |
